# Portafolio Personal 3D Antigravity - Roberto Quintana

## Requisitos
- Node.js 18+
- Docker (Opcional, para deployment)

## Instalación
1. Instalar dependencias:
```bash
npm install
```

2. Correr servidor de desarrollo:
```bash
npm run dev
```

3. Abrir [http://localhost:3000](http://localhost:3000).

## Estructura
- `src/components/3d`: Componentes de Three.js
- `public/models`: Modelos 3D (GLB/GLTF)
